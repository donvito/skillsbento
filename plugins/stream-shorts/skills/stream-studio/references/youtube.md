# YouTube title + description

Write one block per short into `YOUTUBE.md` next to the MP4s, and list the titles in the reply.

## Title (≤ 70 chars, one emoji max)
- Funny: the hook in words, keeping the twist ("My AI works 24/7 for $0* (*terms and conditions apply ⚡)", "2 Codex accounts. 1 day a week. 💀", "I stopped doing free calls. Here's why 👻").
- Educational: outcome + spec ("Free GPU to train AI models (15GB VRAM, $0) 🔥", "Why skills don't bloat your context (but MCP does) 🧩").
- Offer one alternative title.

## Description
```
<1–2 line setup that restates the hook>

<3–6 short lines: the story or the steps (use 1️⃣ 2️⃣ 3️⃣ for tutorials), only real facts from the clip or screen>

<question that invites a comment> 👇

🔴 <where it's from: the stream name, what the channel does>

#shorts #<topic> #<tool> … (6–9 tags)
```
- For tutorials, add "Save this for later 📌" before the question.
- Quote viewers only as they appear on screen. Don't invent stats, links or product claims.
- If the user has a stream or VOD URL, put it on the 🔴 line.
